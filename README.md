# Programas de Programación

## Descripción

Este repositorio contiene los programas, prácticas y ejercicios realizados durante la materia de programación. Incluye ejemplos desarrollados en clase y tareas asignadas.

## Objetivo

El objetivo de este repositorio es documentar nuestro aprendizaje en programación, así como mejorar habilidades en lógica, estructuras de datos y resolución de problemas.

##  Estructura del repositorio

Los programas están organizados por unidades:

* 📁 Unidad 2
* 📁 Unidad 3

##  Tecnologías utilizadas

* Lenguaje: C++
* Compilador: g++
* Librerías: iostream, cstring

##  Cómo ejecutar los programas

1. Descargar o clonar el repositorio
2. Abrir una terminal en la carpeta del archivo
3. Compilar con el siguiente comando:

   ```
   g++ nombre_programa.cpp -o programa
   ```
4. Ejecutar:

   ```
   ./programa
   ```
